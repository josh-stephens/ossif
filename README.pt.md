# OSSIF: Estrutura de Interação Sapiente de Código Aberto

> Uma estrutura para engajamento cívico baseado em evidências, pensamento crítico e coexistência sapiente.

O OSSIF não é um partido político, uma religião ou um produto tecnológico. É um **protocolo para raciocinarmos juntos** — um conjunto de princípios, ferramentas e documentos vivos projetados para ajudar seres sapientes (humanos ou não) a tomar decisões melhores, cobrar responsabilidade do poder e construir uma sociedade digna do que somos capazes de nos tornar.

## Os Sete Imperativos

Estes permanecem estáveis desde o início. Eles são os **Compromissos Fundamentais**:

1. **Quero acreditar em coisas verdadeiras** — Sou um buscador da verdade.
2. **Quero viver em uma sociedade justa.**
3. **Quero respeitar a vida.**
4. **Quero tratar os outros com dignidade e respeito.**
5. **Quero aumentar a prosperidade no universo.**
6. **Quero reduzir o sofrimento no universo.**
7. **Quero aumentar a compreensão no universo.**

Se você pode concordar com estes — não perfeitamente, nem sem esforço, mas como aspirações pelas quais vale a pena se empenhar — então o OSSIF é para você.

## Princípios Centrais de Design

**Código aberto.** Todo documento, toda decisão, toda mudança é pública e controlada por versão. Transparência não é uma funcionalidade — é a própria arquitetura.

**Documentos vivos.** Nada aqui é sagrado ou final. Tudo pode ser revisado por meio de consentimento informado e processo democrático. A versão que você assina é a versão que se aplica a você, e você será notificado quando houver alterações.

**Evidência sobre ideologia.** As afirmações devem ser apoiadas por evidências verificáveis. A incerteza é permitida e rotulada. Asserções infalseáveis não podem conduzir políticas.

**Acessível a todos.** Os documentos são escritos em linguagem simples, evitando o "juridiquês". Versões curadas existem para crianças, para necessidades de acessibilidade e para todos os idiomas que conseguirmos alcançar. Ninguém fica para trás porque as palavras são complicadas demais.

**Protocolo e plataforma.** O OSSIF é tanto um método para o raciocínio quanto um conjunto de conclusões atuais alcançadas pela aplicação desse método. As conclusões — em [Plataforma para o Progresso](docs/platform.md) — são revisáveis. Alguém que aplique o método fielmente e chegue a conclusões diferentes não está errado; está fazendo exatamente o que a estrutura pede. O método é o alicerce. As posições são seu resultado atual, não sua identidade.

## Por Que Agora

Estamos vivendo a convergência de duas crises:

1. **Erosão democrática** — décadas de deriva institucional, desalinhamento de incentivos da mídia e negligência educacional degradaram a aptidão epistêmica de populações inteiras. O resultado: a força começa a parecer "necessária" quando o raciocínio falha.

2. **A transição da IA** — sistemas autônomos capazes de operar por horas ou dias sem supervisão humana estão chegando enquanto nossas estruturas de governança mal conseguem regular as redes sociais. A lacuna entre capacidade e supervisão está aumentando.

O OSSIF existe porque essas crises não podem ser resolvidas separadamente, nem pelas instituições que as produziram. Elas exigem uma nova camada — não um novo governo, mas um novo *piso de raciocínio* no qual os cidadãos possam se apoiar para cobrar responsabilidade de qualquer governo.

## Como Participar

Veja [CONTRIBUTING.md](CONTRIBUTING.md) para detalhes. A versão curta:

- **Leia e pense.** Isso já é participação. Você não precisa se juntar a nada.
- **Abra uma issue.** Discorda de algo? Ótimo. Diga-nos o porquê, apresentando evidências.
- **Proponha uma mudança.** Faça um fork, edite, envie um pull request. É assim que documentos vivos funcionam.
- **Construa algo.** O The Primer, o Portal de Conversação Avatar, o sistema de Token de Confiança — estes são designs aguardando construtores.
- **Fale com as pessoas.** A parte mais difícil e importante. Use a [Versão Resumida](manifesto/one-pager.md) como ponto de partida.
