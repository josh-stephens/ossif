# 创始人的一封信

在你继续阅读之前，我需要对你坦诚一些事情。

我已经逃避这件事三年了。

同样的念头，我写过不下十来遍——在走路时，在开车时，在因腰背旧疾而辗转反侧、大脑无法停止运转时。我填满了 Obsidian 库、ChatGPT 对话、iPhone 笔记和各种碎纸片。我不断地收集、整理、打散、并以不同的结构重新组合这些想法，但始终没有付诸任何实际行动。

我告诉自己，这是因为规模太宏大了。这在某种程度上是真的。我告诉自己，这是因为害怕失败。这在某种程度上也是真的。我告诉自己，这是因为慢性疼痛、懒惰、日常工作的压力，以及抚养四个孩子的混乱生活。

但最根本的原因是：**我到底是谁，凭什么做这件事？如果我错了该怎么办？**

我只是一个在南加州某学区从事 IT 工作的人。我管理服务器，帮老师们修理投影仪。我不是哲学家，不是政治家，不是律师，也不是硅谷创始人。我患有腰背旧疾和肩袖撕裂带来的慢性疼痛。我会拖延。我会感到不知所措。我总是开启了头却没能收尾。

而当我环顾世界，我看到了某种破碎的东西，且我认为没有人在以正确的方式修复它。

我看到一个国家，其半数人口被系统性地剥夺了评估信息所需的批判性思维能力。我看到媒体奖励愤怒而非准确。我看到治理被财富所绑架。我看到技术的发展速度超过了监管。我看到 AI 转型正在降临，而我们甚至几乎无法监管社交媒体。我看到人们被刻意保持愚昧，然后因其愚昧而遭受指责，最后被武器化来反对他们自己的利益。

我看到同样的循环在重复：稳定滋生自满，自满退化制度，退化的制度削弱推理，而推理的虚弱让武力显得有其必要。我们现在正处于第三步，也许是第四步。

我没有答案。OSSIF 也不是答案。OSSIF 是一个**猜想**——一个基于教育、证据、经过深思熟虑的，关于什么可能有所帮助的猜想。这是一个旨在减少伤害的实验，而非对真理的宣称。这是一个共同推理的协议，而非一套被强制采纳的结论。

以下是我的信念：

- 大多数人既不愚蠢也不邪恶。他们只是**缺乏技能且受到的奖惩机制有误**。
- 如果你给人们更好的推理工具，他们中的许多人会使用这些工具。
- 足够数量具备认知素养的公民可以通过合法的民主渠道改变结果。
- 这种方法比革命更容易扩展，比围绕个人建立的运动更容易存续。
- 它必须是开源的，因为任何由个人或公司拥有的东西最终都会被侵占。
- 它必须包含 AI，因为无论我们是否准备好， AI 都会到来。而“准备好”意味着在迫切需要之前，就已经拥有一个框架 f

我以科幻小说中关于不同智慧生命之间纽带的角色来命名我的电脑。我的 VPS 叫 Skippy，取自 Expeditionary Force 系列中一个不敬的 AI。我的工作机是以 Stormlight Archive 中的一个角色命名的，他与一个纯粹的思想体建立了联系。我并没有刻意将此作为 OSSIF 的象征——但回过头来看，我很长一段时间以来一直在围绕着这些关于思维伙伴关系的想法打转。

我创建这个仓库是因为有人告诉我，OSSIF 不必成为一份宣言或一场运动才能真实存在。它只需要成为一个不作任何断言并欢迎批评的 GitHub README 即可。这是一个我可以达到的标准。

所以，它就在这里。它很乱，也不完整。其中的一些想法最终会被证明是错误的、天真的或不切实际的。这没关系。重点不在于完美——而在于**对完美的伦理追求**，以及接受指正的谦逊和继续前进的执着。

如果你读到了这里，并且在这些想法中产生了一些共鸣——感受到你自己的挫败感、你自己的希望、或者是那种“我们可以做得更好”的直觉——那么我想听听你的想法。请提交一个 issue。告诉我在哪里错了。告诉我哪些内容引起了共鸣。告诉我缺失了什么。

我一直站在责任感开始比舒适感更加沉重的边缘。有人告诉我，那通常就是有意义的工作开始的地方。

让我们拭目以待。

— Josh
