# OSSIF: 开源智慧交互框架

> 一个基于证据的公民参与、批判性思维和智慧生命共存的框架。

OSSIF 不是政党、宗教或技术产品。它是一套**共同推理的协议**——由一系列原则、工具和动态文档组成，旨在帮助智慧生命（人类及其他）做出更好的决策，追究权力的责任，并建立一个不负我们所能成就之高度的社会。

## 七项准则

自创立以来，这些准则始终保持稳定。它们是基本承诺：

1. **我渴望相信真实的事物** —— 我是一名真理追求者
2. **我渴望生活在一个公正的社会**
3. **我渴望尊重生命**
4. **我渴望尊严且尊重地对待他人**
5. **我渴望增加宇宙的繁荣**
6. **我渴望减少宇宙的苦难**
7. **我渴望增加宇宙的理解**

如果你认同这些准则——即便无法做到完美，即便仍需努力，但只要视其为值得追求的志向——那么 OSSIF 就适合你。

## 核心设计原则

**开源。** 每一个文档、每一项决策、每一次变更都是公开且经过版本控制的。透明度不是一个功能 —— 它是架构本身。

**动态文档。** 这里没有任何内容是神圣不可侵犯或最终定稿的。一切都可以通过知情同意和民主程序进行修订。你签署的版本即是对你适用的版本，发生变更时你将收到通知。

**证据高于意识形态。** 主张必须有可核实的证据支持。允许存在不确定性并需加以标注。不可证伪的断言不能驱动政策。

**面向所有人。** 文档使用简明语言编写，而非法律术语。我们为儿童、有无障碍需求的人群以及我们所能覆盖的每种语言都准备了精选版本。没有人会因为语言过于复杂而被落下。

**协议与平台。** OSSIF 既是一种推理方法，也是应用该方法得出的当前结论。在 [platform.md](docs/platform.md) 中的结论是可修订的。忠实应用该方法但得出不同结论的人并没有错；他们正是在践行框架的要求。方法是基础，立场是其当前的输出，而非其本质。

## 为何是现在

我们正经历两场危机的交汇：

1. **民主侵蚀** —— 数十年的机构失调、媒体激励错位和教育忽视，削弱了整个人群的认知能力。结果是：当推理失效时，武力开始显得“必要”。

2. **人工智能转型** —— 在我们的治理结构几乎无法监管社交媒体时，能够自主运行数小时或数天的系统正在到来。能力与监管之间的差距正在扩大。

OSSIF 的存在是因为这些危机无法被单独解决，也无法由产生这些危机的机构来解决。它们需要一个新的层面 —— 不是一个新的政府，而是一个新的**推理基座**，公民可以立足于此，向任何政府追责。

## 如何参与

详见 [CONTRIBUTING.md](CONTRIBUTING.md)。简要版：

- **阅读并思考。** 这就是参与。你不需要加入任何组织。
- **提出 Issue。** 不同意某些内容？很好。告诉我们原因，并提供证据。
- **提议变更。** Fork、编辑并提交 Pull Request。这就是动态文档的运作方式。
- **构建。** The Primer、虚拟形象对话门户、信任令牌系统 —— 这些都是等待开发者实现的方案。
- **与人交流。** 最难也最核心的部分。以[单页概览](manifesto/one-pager.md)作为开始。
