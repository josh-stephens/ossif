# OSSIF: オープンソース知的存在インタラクションフレームワーク

> エビデンスに基づいた市民参加、批判的思考、そして知的存在の共生のためのフレームワーク。

OSSIFは政党でも、宗教でも、テクノロジー製品でもありません。これは**共に推論するためのプロトコル**です。つまり、知的存在（人間およびそれ以外）がより良い意思決定を行い、権力の責任を追及し、私たちが到達しうる能力に見合った社会を築くために設計された、一連の原則、ツール、そして生きた文書です。

## 七つの使命

これらは最初から変わることなく維持されてきました。これらは「基本的な誓約」です：

1. **真実を信じたい** — 私は真実の探究者である
2. **公正な社会に住みたい**
3. **命を尊重したい**
4. **他者を尊厳と敬意を持って扱いたい**
5. **宇宙の繁栄を増進させたい**
6. **宇宙の苦しみを軽減したい**
7. **宇宙における理解を増進させたい**

もしこれらに同意できるなら — 完璧にではなく、葛藤しながらであったとしても、目指すべき価値のある志として同意できるなら — OSSIFはあなたのためのものです。

## コア設計原則

**オープンソース。** すべての文書、すべての決定、すべての変更は公開され、バージョン管理されています。透明性は単なる機能ではなく、アーキテクチャそのものです。

**生きた文書。** ここに神聖不可侵なものや最終決定されたものはありません。すべての内容は、インフォームド・コンセントと民主的なプロセスを通じて修正可能です。あなたが署名したバージョンがあなたに適用されるバージョンであり、変更があった場合には通知されます。

**イデオロギーよりもエビデンス。** 主張は検証可能な証拠によって裏付けられなければなりません。不確実性は許容され、その旨が明記されます。反証不可能な断定が政策を動かすことはありません。

**あらゆる人にアクセシブルであること。** 文書は法律用語ではなく、平易な言葉で書かれています。子供向け、アクセシビリティが必要な方向け、そして私たちが到達できるあらゆる言語向けにキュレーションされたバージョンが存在します。言葉が難しすぎるという理由で、誰一人として取り残されることはありません。

**プロトコルであり、プラットフォームであること。** OSSIFは「思考のための手法（推論の作法）」であると同時に、その手法を適用することによって到達した「現在の結論」の集合体でもあります。[platform.md](docs/platform.md)にある結論は修正可能です。手法を誠実に適用した結果、異なる結論に達したとしても、その人が間違っているわけではありません。それこそが、まさにこのフレームワークが求めていることなのです。手法が土台であり、各ポジションはその手法の現在の出力であって、そのアイデンティティそのものではありません。

## なぜ今なのか

私たちは、二つの危機の収束の中に生きています：

1. **民主主義の浸食** — 数十年にわたる制度の漂流、メディアのインセンティブの不一致、そして教育の軽視により、全人口の認識能力（epistemic fitness）が低下しました。その結果、論理的思考が破綻したとき、力による解決が「必要」であると感じられ始めています。

2. **AIへの移行** — 人間の監視なしに数時間から数日間動作可能な自律型システムが登場しつつある一方で、私たちの統治構造はソーシャルメディアを規制することさえままなりません。能力と監視の間の溝は広がり続けています。

OSSIFが存在するのは、これらの危機を個別に解決することはできず、またそれらを生み出した既存の制度によって解決することもできないからです。これらには新しいレイヤーが必要です。新しい政府ではなく、市民がいかなる政府に対しても責任を追及するために立つことができる、新しい「思考の土台」が必要なのです。

## 参加方法

詳細は [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。要約すると以下の通りです：

- **読み、考えること。** それ自体が参加です。何かに加入する必要はありません。
- **Issueを作成すること。** 同意できない点がありますか？ 素晴らしい。その理由をエビデンスと共に教えてください。
- **変更を提案すること。** フォークし、編集し、プルリクエストを送信してください。それが「生きた文書」の仕組みです。
- **何かを構築すること。** The Primer、アバター対話ポータル、トラスト・トークン・システム — これらは構築者を待っている設計図です。
- **人々と対話すること。** 最も困難で、最も重要な部分です。[ワンペーパー](manifesto/one-pager.md)を出発点として活用してください。
