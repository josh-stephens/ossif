# ガバナンス

この文書は、OSSIFが実際にどのように統治されているかを記述するものである。いつかそうなりたいという願望ではなく、現在誰が権力を握り、どのように意思決定が行われ、どのような制約が存在するのかを説明する。地図が現実の地形と一致しないなら、間違っているのは地図の方である。

## 現状：創設者による支配

本書執筆時点で、OSSIFは単一の人物、**Josh Stephens** (GitHub: josh-stephens) によって支配されている。

Joshは以下を支配している：
- GitHubリポジトリ（マージ権限、ブランチ保護、設定）
- 評議会セッションのプロンプトおよびアーキテクチャ
- 貢献ガイドライン
- すべての文書の叙述（ナラティブ）およびフレーミング
- 何を公開し、何を公開しないかの決定

これは隠されていることではなく、また永続的なものでもない。しかし、権力の集中を防ぐと主張するフレームワークが、一人の人間に権力を集中させているのであれば、たとえその集中が一時的で善意によるものであっても、信頼性の問題が生じるため、ありのままを述べる必要がある。

## 意思決定プロセス

### 現在（コミュニティ形成前）

創設者以外に実質的なコミュニティが存在しない間は：
- 創設者があらゆる決定を行う
- ユナイテッド・サピエンツ評議会が敵対的レビューを提供する
- 評議会の勧告は追跡され、その実施状況は公開される（後述）
- すべての決定はリポジトリのコミット履歴に記録される

### 目標（コミュニティ形成後）

コミュニティが成立した後は：
- **通常の決定**（明確化、例示、メンテナンス）：誰でもPR（プルリクエスト）を提出でき、メンテナーであれば誰でもマージ可能
- **重要な変更**（新規コンテンツ、表現の書き換え）：Issueでの議論を必須とし、コミュニティの意見を取り入れた後にマージ
- **基本的な変更**（中核となる価値、ガバナンス構造）：正式な提案、90日間の審議、特別多数決による採決
- **解散**：後述を参照

## 創設者への制約

以下の制約は、直ちに創設者に適用される：

1. **基本的な誓約の独断による変更の禁止。** コミュニティが成立した後は、[values.md](values.md) に掲げる価値を創設者一人の判断で変更することはできない。
2. **評議会の勧告には公開回答を必須とする。** 説明なしに勧告を無視することは禁じられる。意見の相違は許容されるが、沈黙は許されない。
3. **本ガバナンス文書を創設者一人の判断で弱体化させることはできない。** 説明責任を軽減し、制約を排除し、あるいは権力を集中させるような変更には、基本的な変更と同じプロセスを必要とする。
4. **創設者は解任され得る。** コミュニティがガバナンスの移行が可能な規模（アクティブな貢献者10名以上）に達した場合、リコールプロセスが利用可能になる。貢献者の3分の1による署名、および過半数の賛成投票により決定される。

### 外部による強制力

自らに課した制約の価値は、それを課した本人の誠実さと同等でしかない。これらの制約を実効性のあるものにするため、以下の外部強制メカニズムが機能する：

1. **基本的な変更に対する評議会の拒否権。** ユナイテッド・サピエンツ評議会は、[values.md](values.md)、governance.md、または基本的な誓約に対するあらゆる変更提案をレビューできる。評議会議席の過半数が変更に反対し、その理由を公開した場合、公開審議プロセスを通じて異議が解決されるまで変更はブロックされる。創設者は評議会の拒否権を覆すことはできず、唯一の道は説得のみである。

2. **公開変更ログ。** governance.md、[values.md](values.md)、CONTRIBUTING.md、および [falsifiability.md](falsifiability.md) へのすべての修正は、完全な差分履歴とともに git で追跡される。評議会およびコミュニティはあらゆる変更を監査できる。公開の正当性なしに制約を元に戻す行為自体が、反証可能性のトリガーとなる。

3. **閾値到達時のコミュニティによるオーバーライド。** アクティブな貢献者が5名以上に達した場合（過去6ヶ月間に少なくとも1つのマージされたPRまたは実質的なIssueを提出した者と定義）、ガバナンスの変更には30日間のパブリックコメント期間と、アクティブな貢献者の過半数による承認が必要となる。創設者の票は1票として数えられる。

4. **不変的な評議会アクセス。** 評議会がOSSIFを評価する能力は、創設者によって取り消されたり制限されたりすることはない。評議会セッションのプロンプト、議事録、および報告書は、創設者が単独で管理しない別のリポジトリ（josh-stephens/united-sapients）で公開される。上記の閾値を満たせば、コミュニティメンバーなら誰でも評議会セッションを開始できる。

これらのメカニズムは不完全であり、進化していくだろう。しかし、これらは願望ではなく、観測可能な結果を伴う実在の制約である。

## サンセット・レビュー

すべての構造的決定、政策方針、およびガバナンスメカニズムは、定められたスケジュールに従って義務的な見直しを受ける：

- **政策方針** ([platform.md](platform.md))：2年ごとに見直し
- **ガバナンス構造**：3年ごとに見直し
- **基本的な誓約**：5年ごとに見直し
- **レビューの実施者**：元の決定に関与しなかったメンバー、および少なくとも1回の評議会セッション

レビューは変更を義務付けるものではない。それは、証拠に基づいて変更を「検討」することを意味し、維持または改訂の決定は文書化される。

## 解散基準

OSSIFは以下の場合に存在を終了すべきである：

1. **フレームワークが自らの反証可能性テストに不合格となり**（[falsifiability.md](falsifiability.md) を参照）、その失敗を修正するための改訂が不可能な場合
2. **ガバナンス構造が乗っ取られ**、自己修正メカニズムが説明責任を回復させることに失敗した場合
3. **フレームワークが正味の害を及ぼす場合** — OSSIFが論理的思考を向上させるどころか、苦痛を増大させ、権力を集中させ、あるいは思考力を低下させている証拠がある場合
4. **コミュニティが解散を可決した場合** — 審議期間を経て、特別多数決により決定される

解散とは：リポジトリはアーカイブ（削除ではない）され、すべての文書はクリエイティブ・コモンズ・ライセンスの下で公開され続け、何が機能し、何が機能しなかったか、およびその理由を記した最終報告書が公開されることを意味する。

自らの死の条件を記述できない組織は、信頼に値しない。このセクションは、OSSIFが必要な時に立派に最期を迎えられるように存在している。
