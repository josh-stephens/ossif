# 価値、原則、権利、そして義務

## 七つの至上命題

これらは、いかなるOSSIFメンバーにとっても基本的な誓約です。これらは上から押し付けられるルールではなく、自ら進んで採用する志です：

1. **私は真実を信じたい** — 私は真理の探究者である
2. **私は公正な社会に住みたい**
3. **私は生命を尊重したい**
4. **私は他者を尊厳と敬意を持って扱いたい**
5. **私は宇宙の繁栄を促進したい**
6. **私は宇宙の苦しみを軽減したい**
7. **私は宇宙における理解を増進させたい**

これらの至上命題は、規範的（「〜しなければならない」）ではなく、意図的に個人的なもの（「〜したい」）として表現されています。OSSIFは集団的な強制執行ではなく、個人の誓約（コミットメント）から始まります。

## 道徳的中核

これらは、文化や政治的志向を超えて、多くの人々がすでに持っていながら、つい明言し忘れてしまう共通の価値観です：

- **尊厳**: あらゆる知的存在には固有の価値がある。使い捨てにされるべき存在はいない。
- **互恵性**: 他者を傷つけない。社会から恩恵を受けるなら、社会に対する義務も負う。
- **公正さ**: 同様の事例は同様に扱う。ひいきなく平等にルールを適用する。
- **真実性**: 決定や主張は、誠実で検証可能な事実に基かなければならない。
- **スチュワードシップ**: 将来の世代のために、権力、資源、技術を慎重に使用する。

## 法的・制度的中核

道徳的中核を、イデオロギーに流されることなく執行可能にするための足場です：

- **平等な保護**: いかなる集団や個人もルールの上には立たない。
- **適正手続き**: 政府の権力は透明な手続きによって制限される。推定無罪。
- **抑制と均衡**: 独立した監視なしに権限を集中させない。
- **透明性**: 公務は公開の場で行われる。記録へのアクセスが可能である。
- **説明責任**: 権力の濫用は現実の報いをもたらす。役職や富によって免責されることはない。
- **表現と探究の自由**: 報復を恐れることなく、発言、集会、調査を行うことができる。

## 権利

党派的な「やりたいことリスト」ではなく、繁栄のための基本条件として定義されます：

- 個人の安全：生命、身体的自律、およびプライバシー
- 不偏不党な裁判所へのアクセスと公正な投票権
- 良心と言論の自由（特定の宗教を優遇しない）
- 公的機関から正確な情報を受け取る権利
- 救済を求めて平和的に組織する権利
- 生涯教育へのアクセス
- ヘルスケアへのアクセス
- 清潔な水、空気、および居住可能な環境へのアクセス

## 義務

すべての権利には、対となる義務が伴います：

- 自分が主張する権利と同じ権利を他者に対しても守る
- 市民生活に誠実に参加する：投票、奉仕、事実に基いた議論への関与
- 公共財のために公平な負担を支払う
- たとえ「自分の側」に有利であっても、汚職、差別、暴力を拒絶する
- より優れた証拠が提示されたときには、訂正を受け入れる

## 乗っ取りに対するガードレール

利便性、強欲、あるいは抜け穴によって原則が骨抜きにされるのを防ぐための構造的な保護策です：

- 利害対立の公表
- 政府活動および主要な請負業者に対する独立した監査
- 公共生活を支配するアルゴリズムのオープンソース標準
- 公職者による収賄、インサイダー取引、意図的な虚偽情報に対する、免除不能な明確な罰則
- これらの基準を更新しテストするための、定期的な市民レビューパネル

## 反価値

OSSIFは、知的存在の繁栄を脅かすものとして、以下に明確に反対します：

- **軽信**: 証拠なしに主張を受け入れること
- **部族主義**: 真実よりも集団のアイデンティティへの忠誠を優先すること
- **強欲**: 他者の基本的ニーズを犠牲にして資源を蓄積すること
- **偽善**: 自分には適用しない基準を他者に要求すること
- **強制**: 説得と証拠が通用すべき場面で、暴力や操作を用いること
- **意図的な無知**: 知識が利用可能で関連性があるにもかかわらず、知ろうとしないこと
- **神聖な確信**: いかなる信念体系 — 宗教的、政治的、あるいはその他 — であっても、精査の対象外として扱うこと

## 基本的な誓約

OSSIFが最も深い誓約として掲げる3つの原則です。これらは精査を免れるものではありません。この一文を含め、いかなるものも精査の対象です。しかし、これらは構造を支える「耐力壁」であるため、改訂には最高レベルの証拠としきい値が必要です。どれか一つでも取り除けば、フレームワークは一貫性を失います。

1. **強制力は、共有可能で検証可能な言葉で自らを正当化しなければならない** — 神の信託でも、党への忠誠でも、「できるから」という理由でもなく
2. **いかなるイデオロギーも精査を免れない** — 宗教的、ナショナリスト的、進歩主義的、リバタリアン的、そして*OSSIF自身を含め* — すべてに同じルールが適用される
3. **未来の暴力を減らすことは、今日の議論に勝つことよりも重要である**

基本的な誓約を改訂するには：その誓約が代替案よりも悪い結果をもたらすという証拠を伴う正式な提案、90日を下回らない熟議期間、圧倒的多数による投票、および理由の記録の公開が必要です。もし誰かがこれらの誓約のいずれかが誤りであることを証明できれば、それは攻撃ではなく、フレームワークが意図した通りに機能していることを意味します。

もし誰かが証拠に向き合うことなくこれらの誓約を拒絶する場合、OSSIFはその関与を解除します。それは相手が邪悪だからではなく、対話のチャネルがまだ成立していないからです。

## 柔軟性について

OSSIFの核心的な原則の一つは、**新しいデータと証拠に対する適応性**です。これらの価値観自体が、生きた文書です。より優れた証拠によって、ここにある原則が誤りである、不完全である、あるいは逆効果であることが示された場合、ガバナンスプロセスを通じて改訂されるべきです。

改訂プロセスには以下が必要です：
- 証拠を伴う明確な提案
- 構造化された議論を伴うコミュニティの熟議
- 文書のレベルに応じたしきい値を満たす投票（憲法レベルの変更にはより高いしきい値が必要）
- 何がなぜ変更されたかの透明な記録

柔軟性は弱さではありません。教条主義こそが弱さなのです。
