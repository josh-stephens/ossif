# 价值观、原则、权利与义务

## 七项准则

这些是任何 OSSIF 成员的基本承诺。它们并非自上而下强加的规则，而是你选择去追求的志向：

1. **我想相信真实的事物** —— 我是一个真理寻求者
2. **我想生活在一个公正的社会**
3. **我想尊重生命**
4. **我想以尊严和尊重对待他人**
5. **我想增加宇宙的繁荣**
6. **我想减少宇宙的苦难**
7. **我想增加宇宙的理解**

这些准则有意地设定为个人化的（“我想……”），而非强制性的（“你必须……”）。OSSIF 始于个人承诺，而非集体强制执行。

## 道德核心

这些是跨越文化和政治取向的、大多数人已经持有但往往忘记清晰表述的重叠价值观：

- **尊严**：每一位智慧生命都有其内在价值。没有人是可被抛弃的。
- **互惠**：不伤害他人。如果你从社会中获益，你也对社会负有责任。
- **公平**：类似情况同等对待。规则平等适用，不搞偏袒。
- **真实性**：决策和主张必须基于诚实且可核实的事实。
- **受托责任**：以关怀子孙后代之心，审慎地行使权力、利用资源和技术。

## 法律与制度核心

这些框架使道德核心得以执行，而不会漂向意识形态：

- **平等保护**：没有任何团体或个人能凌驾于规则之上。
- **正当程序**：政府权力受透明程序的限制。适用无罪推定。
- **制衡**：没有不受独立监督的权力集中。
- **透明度**：公共事务公开进行。记录可供查阅。
- **问责制**：滥用权力会导致实际后果。职权或财富不能豁免。
- **自由表达与探究**：人们可以说话、集会和调查，而不会受到报复。

## 权利

这里的权利被设定为繁荣的基本条件，而非党派的愿望清单：

- 人身安全：生命、身体自主权和隐私
- 获得公正法庭审理和公平投票的权利
- 思想和言论自由，不给予宗教特权
- 从公共机构获取准确信息的权利
- 和平集会寻求救济的权利
- 接受终身教育的权利
- 获得医疗服务的权利
- 获得清洁水、空气和宜居环境的权利

## 义务

每一项权利都对应着一份义务：

- 维护你为自己主张的同样权利
- 诚实地参与公民生活：投票、服役、参与基于事实的辩论
- 为公共产品支付公平的份额
- 即使在对自己“阵营”有利的情况下，也要拒绝腐败、歧视和暴力
- 当面对更有力的证据时，接受指正

## 防止被蚕食的护栏

这些结构性保护旨在防止便利、贪婪或漏洞削弱原则：

- 利益冲突的公开披露
- 对政府运作和主要承包商进行独立审计
- 管理公共生活的算法应采用开源标准
- 针对公职人员的贿赂、内幕交易和蓄意传播虚假信息的行为，设定明确且不可撤销的处罚
- 定期设立公民评审小组以更新并测试这些标准

## 反价值观

OSSIF 明确反对以下威胁智慧生命繁荣的行为：

- **轻信**：在没有证据的情况下接受主张
- **部落主义**：忠于群体身份而非真理
- **贪婪**：以牺牲他人的基本需求为代价积累资源
- **虚伪**：对他人的要求标准不适用于自己
- **强迫**：在说服和证据本该起作用的地方使用武力或操纵
- **刻意无知**：在知识可用且相关时选择不去了解
- **神圣的确定性**：将任何信仰体系（宗教、政治或其他）视为不容置疑

## 基本承诺

OSSIF 视为其最深切承诺的三项原则。它们并非不容置疑 —— 没有任何事物（包括这句话）是不容置疑的。但修订这些原则需要最高门槛的证据和共识，因为它们是承重结构：移除其中任何一项，整个框架就会失去连贯性。

1. **强制性权力必须以共享且可核实的方式证明其合法性** —— 而不是凭神授、党派忠诚或“因为我们可以”
2. **没有任何意识形态能免于审查** —— 宗教、民族主义、进步主义、自由意志主义，*包括 OSSIF 本身* —— 都要遵守同样的规则
3. **减少未来的暴力胜过赢得今天的争论**

修订基本承诺的过程：一份正式提案并附带证据证明该承诺产生的结果比替代方案更差；不少于 90 天的审议期；绝对多数票决；以及发布理由记录。如果有人能证明这些承诺中的某一项是错误的，那并不是一种攻击 —— 而是框架正按预期运行。

如果有人在不接触证据的情况下拒绝这些承诺，OSSIF 就会停止接触 —— 并不是因为他们邪恶，而是因为沟通渠道尚不可行。

## 关于灵活性

OSSIF 的核心原则之一是**对新数据和证据的适应性**。这些价值观本身也是动态文档。如果有更有力的证据表明这里的某项原则是错误的、不完整的或适得其反的，则应通过治理程序进行修订。

修订程序需要：
- 附带证据的明确提案
- 带有结构化讨论的社区审议
- 符合该文档级别门槛的投票（宪法级变更需更高的门槛）
- 关于变更内容及其原因的透明记录

灵活性不是弱点。教条才是。
